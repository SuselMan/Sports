# Правила проекта


## Единый UiKit · правило владельца 19.11.2026

Для общих интерфейсов использовать только SuselMan/UiKit как Git submodule.
Не копировать библиотеку и не создавать отдельные реализации общих компонентов.
Универсальные компоненты без бизнес-логики развивать в UiKit, соблюдать его
токены и стилистику. При любом изменении проверить всех потребителей и обновить
их сабмодули на один опубликованный проверенный SHA. Правила и список
потребителей — AGENTS.md и CONSUMERS.md самого UiKit; общий регламент —
~/projects/vps-infra/docs/shared-ui-kit.md. Deploy и переключение сервисов отдельно.

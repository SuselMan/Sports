# Kektrack Android

Офлайн-приложение дневника тренировок. Android 8+ (API26), Java8/JDK17,
SDK platform35 и build-tools35.0.0. React/Vite ресурсы упакованы в APK.

Сборка: `git submodule update --init`, `npm ci --prefix frontend`,
`npm run build --prefix frontend`, `./android/build.sh`.
Результат: android/build/kektrack.apk. Ключ обновлений и пароль автоматически
создаются приватно в ~/.local/share/kektrack-apk-signing. Их нужно сохранить;
APK без сохранённого ключа не обновит прежнюю установку. Ни адреса здоровья,
ни токены, ни история пользователя не входят в APK.

В настройках включить передачу в «Здоровье», указать HTTPS endpoint
`/api/kektrack` и отдельный токен со страницы подключения выбранного профиля.
Отправляется полный снимок таблиц IndexedDB, включая архивные отметки.
Автоотправка после изменений, при возвращении в приложение, появлении сети
и раз в минуту, пока процесс активен; без изменений пакет не отправляется.
При закрытом приложении фонового задания нет. Сбой не удаляет локальные
записи. Ручная отправка повторяет снимок даже без новых изменений.

Токен сохраняется в приватном хранилище WebView; Android backup отключён.
Произвольные внешние страницы, файловые URL и контент-URL в WebView запрещены.
Нативная отправка по HTTPS, без редиректов, с таймаутами и проверкой ответа.
В релизе WebView debugging отключён. Для QA: `KEKTRACK_DEBUG=1 ./android/build.sh`;
после проверки снова собрать без этой переменной и установить релиз.

JSON-копия сохраняется через системный выбор файла; импорт через системный
file picker объединяет данные по _id и updatedAt, не затирая более новые.
Копия содержит личные записи, но не настройки соединения/токен. История
веб-PWA и APK не общая. Перенос из браузера требует веб-версии с кнопкой копии.
Google-вход и прежняя серверная синхронизация Sports остаются отключёнными.

Версия1.1: безопасные отступы применяются к контейнеру WebView с учётом
системных панелей, выреза экрана и клавиатуры; снизу дополнительно8dp.
Цвет свободных областей и контраст системных значков следуют теме приложения.
Значок лаунчера — исходный frontend/public/512.png из PWA; adaptive-icon
с белым фоном и внутренним отступом для разных масок Android.

Версия 1.2 (versionCode 3): импорт справочника упражнений через JSON
`kektrack-exercises-v1` на экране «Упражнения», с предпросмотром, отменой,
атомарным добавлением и пропуском совпадающих названий. Текущая история
и настройки сохраняются. Формат описан в корневом README.

Проверка импорта: запустить Vite на 127.0.0.1:5188 и
`node tests/exercise-import.cjs` (PLAYWRIGHT_MODULE задаёт путь к Playwright).
Тест работает в отдельном browser context без пользовательских данных.

Версия 1.3.6 (versionCode10): сохраняется календарный день `calendarDate`
при создании/редактировании подходов и показателей. Экспорт в «Здоровье»
и резервная копия добавляют его также для старых записей по текущему часовому
поясу устройства; уже сохранённый день не пересчитывается при смене пояса.
Это устраняет сдвиг дня на сервере после перехода на зимнее время.
После обновления нажать «Отправить сейчас». Если старые записи создавались
в другом поясе, проверить выбранные даты перед повторной отправкой.
Проверка: `node tests/calendar-date.cjs` при Vite на127.0.0.1:5188.
